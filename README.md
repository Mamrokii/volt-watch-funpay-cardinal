# ⚡ VOLT Watch — сторож лотов для FunPay Cardinal

Бесплатный плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal), который следит за твоими лотами и сразу сообщает в Telegram, если какой-то лот пропал с профиля.

Лоты пропадают незаметно: их снимает модерация, они деактивируются после продажи или их удаляют по ошибке. Пока ты не заметил, продаж нет. VOLT Watch заметит за тебя.

## ✨ Возможности

- 🔍 Каждые 15 минут сверяет активные лоты на профиле с прошлой проверкой
- ⚠️ Уведомление в Telegram, если лот пропал: название, раздел и ID
- 🆕 Сообщает о новых активных лотах
- 📦 Команда `/lots` — сколько активных лотов в каждом разделе
- 🤫 Без спама: при запуске только запоминает лоты, о каждом изменении сообщает один раз

## 📥 Установка

1. Останови FunPay Cardinal.
2. Скопируй `volt_watch.py` в папку `plugins` Кардинала.
3. Запусти Кардинал. В логе появится `[VOLT Watch] Слежу за N лотами.`

Уведомления и команда `/lots` работают через Telegram-бота Кардинала.

**Совместимость:** FunPay Cardinal 0.1.17+ (sidor0912), Python 3.12+.

## ⚙️ Настройки

В начале файла `volt_watch.py`:

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `CHECK_INTERVAL` | `15 * 60` | Как часто проверять лоты (в секундах) |
| `MAX_ITEMS_IN_ALERT` | `15` | Сколько пропавших лотов показывать в одном уведомлении |
